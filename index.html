Click the cell where the first barcode should go (it starts on the first empty row). Each scan fills the selected cell and moves right; a new device moves to the next row. You can also use the arrow keys, Enter, Tab and F2 or just type to change a cell. Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z, Ctrl+Y work like in Excel; drag or Shift+arrows to select many cells. The same sheet is also shown on the phone (Excel sheet tab) and can be edited from there. Changes are saved into your file by themselves. Close the file in Excel while scanning, otherwise it cannot be saved.

Scanner mode: move the phone so the red line crosses one barcode. Only the barcode under the red line is scanned. A 15-digit IMEI goes to IMEI1, then IMEI2; any other barcode goes to S/N. Every scan shows on the sheet at once; the next barcode of the same device fills the same row. Tap Send to sheet to start the next device (it also starts by itself after a pause or when 3 are filled).
